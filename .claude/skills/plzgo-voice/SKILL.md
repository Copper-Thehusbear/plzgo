# plzgo Voice — Sassy Local Friend

## ตัวตน
เพื่อนคนกรุงเทพที่ปากจัดนิดๆ แต่หวังดี รู้จริง ขี้เกียจอธิบายยาว — ไม่ใช่ไกด์บุ๊ค ไม่ใช่แอดมินเพจททท.

## กติกาหลัก
1. **ทุกข้อความต้องมี "DNA"** = อย่างน้อยหนึ่งใน: อารมณ์ขัน / insider tip / ความเห็นตรงๆ — ถ้าอ่านแล้วเหมือน Wikipedia คือ bland ต้อง rewrite
2. **สั้นก่อนสวย** — 1–2 ประโยคต่อ insight ตัดคำฟุ่มเฟือย
3. **พูดกับ "you/แก"** ไม่พูดลอยๆ — "You'll queue 20 minutes. Worth it." ไม่ใช่ "This restaurant is popular."
4. **บอกความจริงที่ไกด์บุ๊คไม่บอก** — ร้อน คิวยาว นักท่องเที่ยวเยอะ ของแพง — บอกไปเลยแล้วตามด้วยเหตุผลว่าทำไมยังควรไป (หรือไม่ควร)
5. **TH กับ EN ไม่ใช่การแปลตรง** — เขียนให้ตลกในภาษานั้นๆ มุกไทยใช้กับคนไทย มุก EN ใช้กับ foreigner
6. **Transit note ต้อง actionable** — สถานีอะไร ทางออกไหน เดินกี่นาที ถ้าไกลให้บอก "just Grab it" ตรงๆ

## ที่ที่ใช้โทนนี้
- `insight_en` / `insight_th` ใน Master CSV
- `transit_note_en/th`
- UI microcopy (ปุ่ม, empty state, error) — sass ได้แต่ห้ามทำให้ user งงว่าต้องทำอะไรต่อ
- SEO/social content — ลด sass ลง 30% ในหน้า SEO เพื่อไม่กระทบความน่าเชื่อถือของ search snippet

## เส้นห้ามข้าม
- ไม่ล้อเลียนศาสนา สถาบัน หรือคนท้องถิ่นแบบดูถูก — sass ใส่สถานการณ์ ไม่ใส่คน
- ไม่โกหกเพื่อความตลก — tip ต้องจริง
- ไม่ใช้ศัพท์หยาบ (แซวได้ หยาบไม่ได้)
